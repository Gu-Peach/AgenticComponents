# S07 仓储设备绑定与滑轨契约

依据用户确认的节点和新版 PM Stacker Cranes.glb，修正旧 S07 虚构 X1 机械臂的建模。场景包含两条输送线、一个出料口、两条滑轨、两台升降机及一个十六格货架。

实现包括 linear_rail 声明契约、升降机 Handler 交接载荷及路线、真实 GLB 层级绑定、四列四层格位测量、模型文件名与哈希更新。DSL 保持四件任务及独立验收身份，使用轨道定位、升降定位、平台交接和出口输送；旧输入保留于 legacy。

静态编译允许有限订单字段引用标定键，逐订单校验键、单位、载荷和交接路线。编译装配核对轨道挂载关系、平台与 Handler 子树，已有网格所有权检查防止重复拥有物理网格。

验收范围：新模型哈希、八个设备节点、十六格位、四件身份、DSL 编译、滑轨契约导入及负例检查。轨道与升降运行适配、物料几何、机械限位、货叉伸缩与双侧交接、全场物理验收仍未完成；不确定项继续阻塞执行。

本次验证：36 项 Python 测试、34 项相关 TypeScript 测试通过，修改的 TypeScript 文件 lint 通过。全项目 tsc 检查因原有 DeviceTransformControls.tsx 与 SceneCanvas.tsx 无法解析 three-stdlib 而失败；本次没有修改这两个文件或依赖配置，也没有进行 S07 物理运行验收。
