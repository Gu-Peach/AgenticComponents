# 012 场景播放控制、动画刷新与 PLC 面板

2026-11-23。开发前计划及实施验收记录。

## 当前行为

三维视口从 SceneRuntimeController 的界面订阅读取位姿。控制器通常每六个 1/60 秒物理步发布一次，相当于每秒十次位姿更新。顶栏目前只连接单设备运行器和预览器。PLC 面板使用 BOM 的 selectedId 查找场景，点空白处后会显示 Main.st。

## 实施顺序

1. 在工作区保存当前场景实例的身份。导入场景后打开 PLC 梯形图，随后选择设备或取消选择都保留该场景。多场景时允许切换，已准备或运行的会话优先。打开已保存工程、移除场景和新建工程时同步更新。
2. 将顶栏播放控制连接至当前场景的同一个运行会话。开始时自动准备，暂停后从原 tick 继续，停止走受控停止流程，正常结束后可重新播放。提供数值倍率输入，默认 1 倍，首版支持 0.1–4 倍。无场景时沿用现有单设备控制。
3. 物理继续使用固定 1/60 秒步长。倍率调整每帧累计的仿真时间，限制单帧补算工作量。三维位姿更新与 PLC 界面通知分开，按渲染帧消费最新位姿，减少重复快照和无效模型变换。暂停、停止、重置和后台切换时按当前会话状态同步。
4. 用时钟测试检查各倍率下的逻辑 tick 和暂停恢复。用场景测试与浏览器验证导入后直接显示 PLC、取消选择、顶栏启停、倍率修改、重新播放及错误提示。以同一场景比较位姿更新频率，记录测量条件与限制。

## 验收

顶栏和 PLC 显示相同的场景与运行状态。用户能输入小数倍率；修改倍率后已执行的工步和物理步长保持一致。在正常播放时，视口可在 PLC 两次刷新之间显示运动。用户主动切换到资产或终端页签后，工步推进不会强行切回 PLC。

## 实施结果

导入场景或恢复含场景的工程后，底部自动展开 PLC。多场景工程默认显示最近导入的场景，可在 PLC 面板中切换。仿真期间，顶栏、梯形图与三维视口共用同一会话。点击空白、选择普通设备以及手动切换页签都保留当前场景。

顶栏的播放按钮负责准备并启动场景。暂停后点击继续会保留运行身份和当前工步。点击停止会请求受控停止，停止完成后点击重新播放会创建新会话。速度框支持 0.1 至 4 倍的小数，按 Enter 或移开焦点生效。倍率影响每帧推进的 tick 数。后台切换会暂停，低帧率时限制补算时间以保持界面响应。

场景播放基准已调为原来的四倍。默认显示 1×，对应原来的 4×；输入 0.25× 可使用原来的 1×。界面计时显示仿真时间，物理步长为 1/60 秒。

三维视口在渲染帧上读取相邻物理步的样本，对刚体位置、旋转和机器人关节角进行插值。暂停时显示最近的实际物理位姿。物料按准入顺序创建可视克隆；场景选框复用加载时计算的边界。PLC 继续按较低频率更新，启停与故障状态立即发布。
