# S11 人工搬运、转台分度与机械臂加工

## 模型与工艺

沿用 S11 原任务的四件工单 M01–M04。GLB 中有一件 `Workpiece`，其初始位置和下方小车作为批次供料与收料依据。逐件供料，交付上一件后才接纳下一件。人物使用 `Human`，转台使用 `Indexing_Table(center)`，加工机械臂使用 `robot(ARC-2000i)`。初始台面有人侧和机器人侧两个方向，同一件物料跟随同一个台面接口往返。

## 改动顺序

1. **定义设备与接口。** 人物契约提供搬运行为，绑定手部吸附点，动作含接近、吸附、平移、放置和撤离。转台契约提供承载接口、转轴、旋转部件与分度行为；起转要求指定物料已固定、人员已离开、机器人已退位，完成要求实际到角、停稳、同件仍在台上。机器人增加加工行为，声明工具工作点、适用工艺与可配加工时长。每件物料分别声明抓取接口与加工接口，加工性质由机械臂完成动作时更新。
2. **绑定真实模型。** 检查人物右手、旋转部与固定底座、工装位置、工件装夹方向、机械臂六关节及焊枪尖。根据工具和工件接口的局部坐标解算目标姿态，在完整模型上验证实际可达性。记录缺少独立标记的候选点及仿真参数。
3. **实现动作与互锁。** 用物理步驱动人物平移、吸附约束、带载旋转和机械臂关节运动。每次分度沿同一方向走 180°，第二次完成后工装回到人侧。机械臂必须在转台停稳、工件加工接口与工具对准后累计加工时间；停止或失去条件时保留已有工件状态。请求、设备忙、完成或故障及现场观测接入现有 PLC 与条件调度。
4. **接入场景。** 使用已有声明式 DSL 的有限工单、顺序、循环和设备调用。每件依次执行人物上料、转台分度、机器人加工并退位、转台再次分度、人物下料。每件独立验收加工记录与交付记录，整批结束要求转台停稳、人员空手、机器人退位。
5. **验证。** 从工作台目录导入并准备候选仿真。在真实 GLB 与 Jolt 世界验证四件完成、两次旋转的方向与角度、工具对接误差、工件身份、停止与恢复初态。回归既有机械臂加工及托盘、仓储、双臂场景。

此版人员动作以模型平移和手部约束表现，显示时使用肩、肘和腕关节将掌面对准吸附点。焊接以工具对接、工艺时间和完成回执表现，工件保持原模型外观。

## 验收记录

- 从工作台目录导入真实模型并准备候选仿真。四件材料按原工单顺序完成八次正向分度、四次焊接和四次交付，终态为第 9,258 个固定步（60 Hz）。每件的加工回执记录工位、工具与工件接口、配方、实际对接偏差及持续步数。
- 可见手掌跟随吸附点，脚保持落地。转台底座固定，旋转部及工件同步转动；可见焊枪尖的姿态和引擎关节计算一致。
- 转台中途停止会减速并保留台上工件。加工中停止会保留原料状态。人物持件停止时保持吸附，显式放弃会话并重新准备后，首件回到小车。
