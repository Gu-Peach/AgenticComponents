# Runtime dependency

The contact transport experiment uses JoltPhysics.js 1.1.0-oip.9 (MIT), the local Open-Industry fork, pinned through vendor/jolt-physics-1.1.0-oip.9.tgz. The archive includes upstream LICENSE and package metadata. Source provenance: https://github.com/jrouwe/JoltPhysics.js and E:/project/Open-Industry/vendor. The application uses its single-thread WASM-compatible build and a separate contact adapter; no commercial vendor behavior is used.
