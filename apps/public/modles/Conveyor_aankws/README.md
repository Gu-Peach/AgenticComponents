# Conveyor_aankws declarative rigid body

设备 0.6.0 / 契约 1.3。physics.bodies.belt_body 为 static，conveying_surface.body_ref 绑定它，通过接触表面速度输送动态物料。方向权威为 flow_axis/normal；当前工艺区域仅支持水平局部 +X/+Y、单位缩放。

局部入口 [-0.749,0.700,0]、出口 [0.751,0.700,0] 仅用于空间吸附。有效带面长 1.4 m、宽 0.5 m，顶面高 0.7 m，厚度参数 0.1 m；碰撞中心高度由带高减半厚度派生。摩擦 0.6、反弹 0 为仿真设定。

添加本设备和 engine_block 实例，在右侧选择物料、填写明确的实验质量，点击“物料放到入口并对齐”，再启动。运行不生成替代箱体，不改写作者位姿。停止/重置恢复真实物料作者位姿；到达出口仅表示观察任务完成，未实现下游交接。

观测区域区间直接来自 schema；支承由接触记录生成。kinematic、非盒代理和多设备共同运行尚未支持，不能仅修改标记绕过。旧 1.2 定义保留兼容实验，不自动升级。
