# robot_UR10 仿真实验模型

设备定义：`schema.json`，契约 1.4，定义版本 0.1.0。模型文件保持源 GLB 字节不变；SHA-256 与 schema.calibration 一致。

## 模型与运动

GLB 有 48 个源节点、25 个 mesh，无动画、无骨骼。运动关节为 Link1_003n、Link2_004n、Link3_005n、Link4_006n、Link5_007n、Link6_008n；Link1_001n 是支架层。根矩阵已含约 0.01 缩放及绕 Y 旋转，不再增加导入缩放。

米制关节间静止位姿来自完整源父链；渲染保留原层级，在每个关节原始局部旋转后乘上关节增量。q=0 是源资产静止姿态，不是实机编码器零点。TCP 为 mountplate_009n 原点的虚拟工具参考。可用 `node scripts/inspect-robot-model.mjs` 复核源资产。

## 参数来源与能力

六轴局部轴依次选用 +Y、+Z、+Z、+Z、+X、+Y。各关节 ±π、速度 0.8 rad/s、加速度 1.5 rad/s²、载荷 5 kg 等均为本项目显式选用的仿真实验配置，未按厂商数据标定，不代表实机 UR10 指标。配置状态 simulation_configured 不等同于实机校准。

运行模板 robot.articulated@1 支持单臂位置 CCD IK、同步关节 PTP、仿真时间等待、有效信号等待、任务输出、减速保持及恢复。PTP 不保证 TCP 直线轨迹；不支持姿态 IK、自动避障、全臂碰撞、力矩控制或 PLC 执行。

## 固定约束抓放

工具为 0.025 m 的运动学盒代理，捕获参考为物料盒顶部沿局部 Y 再偏移 0.025 m。采用半径 0.06 m 的虚拟球形捕获，接受所有朝向；这是无实体夹爪的实验工具，不冒充真实夹具姿态约束。

抓取检查指定物料身份、单会话独占、质量/载荷、捕获距离和相对速度。Jolt 固定约束保持抓取瞬间相对位姿，不瞬移物料；只过滤工具/当前持有物料这一对的碰撞。携物目标基于持有偏移求解物料中心，放置高度考虑旋转后的外形。释放后由 Jolt 继续求解；指定目标有效支承、位置和速度判据成立后才报告交接成功。

首个物理世界仅含虚拟工具、指定物料、选定静态传送带支承与地面；其他场景物体不参与。物料必须先手动放到可达且稳定的位置并填写质量，不在运行启动时重排作者场景。

## 已验证实验布局

可在单位缩放下使用：robot 原点 [0,0,0]；Conveyor_aankws 位置 [0.099129,0,-0.647548]；engine_block 位置 [-0.020371,0.7,-0.647548]、绕 Y 90°、仿真质量 1 kg。先在机械臂面板选择该物料和支承，准备物理抓放，再执行抓放任务。此布局是确定性验收实例，不是任意布局都可达的承诺。

会话停止/重置后恢复源关节和作者物料位姿；运行快照不写回项目定义或实例参数。
