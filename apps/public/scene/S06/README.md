# S06 托盘九件逐件加工回位

`process.py` 声明一盘九件。三段主线同步运行，将预装毛坯的托盘送至第二段加工工位。机械臂按模型槽位顺序抓一件、送入机床、归位。机床加工完成后，机械臂取回同一件成品，放回它的原槽并再次归位。全部九件完成后，托盘从第三段出口离开。

| 设备或物料 | 模型绑定 | 用途 |
| --- | --- | --- |
| F1 | `__Geometry___006c` | 初始满盘供料台 |
| C1、C2、C3 | `Conveyor_00Jn`、`Conveyor_#2_001n`、`Conveyor_#4_000n` | 主线沿世界 −X 输送，工位采用 `Process_Node_#2_002n` 在带面上的投影 |
| R1 | `RobotController_00bn` | 绑定六个 Axis 关节，法兰为 `mountplate_00kn` |
| MC1 | `Parametric_Vertical_Mill_00Kn` | 唯一加工接口 `MC1.work` 绑定 `Workpiece_00Zn`，对应工作台顶面 `Mesh_05zg` |
| P01 | `__Geometry___007c` 与垫板 `__Geometry___008c` | 共用父节点 `AssemblyBaseComponent_007n`，物料均单独绑定 |
| M01_01 至 M01_09 | `__Model___009v` 下的 `Lathe_Comp_1_00An` 至 `Lathe_Comp_1_00In` | 3×3 毛坯，每件绑定独立几何、运行身份与原槽 |
| 成品外形 | `Lathe_Comp_3_004n` | 加工成功后切换同一物料的外观，托盘槽位和身份贯穿整个工艺 |

## 加工约定

当前 DSL 将 `item.source` 显式传给返程抓放的 `target`。若工艺选用同一托盘上另一个已声明的空槽，可在 DSL 中指定该目标并同步更新独立验收清单。引擎按实际支承、占用和放置回执登记去向。

机床执行 `machine_material(subject_id)`。毛坯的初始性质为 `raw`。机床确认指定物料在加工点受到支承，且机械臂已归位后才能开始。周期结束后，机床提交 `finished` 状态并反馈当前请求的结果。供料台上的九个毛坯来自原始模型，成品模板和散放的毛坯样件仅提供外形。

候选周期为每件 2 仿真秒，可在 `device/MC1.json` 的 `cycle_time_s` 调整。毛坯与成品的外包络实测高度均约 0.20 米、最大直径约 0.18 米，仿真沿用同一个碰撞包络，并以 1 千克作为单件仿真假设。机床工作点 Y 约 0.788 米，距离台面上沿约 0.18 毫米。托盘垫板的模型顶面高于毛坯原点约 1 厘米，回放保留原槽水平位置，高度按实际承载面计算。

独立验收在 `task-spec.json` 声明九个物料的加工点、原槽及整盘离开条件。
