# S04 双臂瓶体交接与倒置输送

按工艺顺序为机械臂编号。R1 靠近第一条输送带，R2 靠近第二条输送带。

| 实例 | GLB 节点 | 职责 |
| --- | --- | --- |
| S | `__Geometry___00Cc` | 有限供料 |
| Bottle | `Sleeved_Bottle_00En` | 瓶体预制体。首件采用现有节点，其余按任务准入 |
| C1、C2 | `Conveyor(1)`、`Conveyor(2)` | 瓶底朝下进料、瓶头朝下出料 |
| R1 | `robot(UR10)(2)` | 从 C1 抓瓶头，和 R2 悬空交接 |
| R2 | `robot(UR10)(1)(center)` | 从瓶底接取、翻转并放到 C2 |

瓶体高度约 0.215 m，最大直径约 0.060 m。瓶底中心是局部坐标原点，局部 +Y 指向瓶头。`head` 和 `tail` 是同一个刚体上的抓取坐标系，分别绑定瓶盖顶部中心与瓶底中心。夹具从各自一端接近，两者共用一个物料身份。[瓶体契约](contracts/workpiece.json)

DSL 采用 ac-declarative/0.4，保留四件任务，逐件调试。S 将瓶体直立供给 C1。C1 定位并停稳后，R1 从瓶头抓起，把瓶体水平送到 `R1.handoff`。R2 对准瓶底，确认持有权转移后，R1 退出并回位。R2 用瓶底夹持翻转瓶体，按 `C2.entry` 定义的姿态放下，之后 C2 将瓶体送到出口。C2 进出口以瓶头接触点为参考，输送全程要求局部 +Y 朝向场景 −Y，且瓶头与带面保持支承。[工艺 DSL](process.py) · [出料带姿态](device/C2.json) · [验收目标](task-spec.json)

双臂交接由同一请求协调。候选执行器同时获取双臂控制权和物料预留权，确认接方姿态及相对速度后，再把物理固定约束从 R1 转给 R2。转移失败时保留现有持有关系。中途停止时保留夹持和物料身份，停止后可放弃本次仿真并恢复初态。

两台臂的六级枢轴间距逐级匹配仓库内 UR10 参考模型。关节局部轴为 `+Y、+Z、+Z、+Z、+X、+Y`，以 GLB 静止姿态为零位，采用参考模型的 ±π 候选行程。TCP 绑定各自法兰原点。夹具通过轴向虚拟接触点建立物理固定约束，抓取时确认实际物料位置、夹具方向和相对速度。交接位置取两臂静止法兰的中点。

准备完成后从 PLC 或顶栏启动。S04 在候选仿真模式中使用 `robot-handoff@1`。Jolt 验收通过单瓶和四瓶任务，分别在 tick 4036 和 16035 完成交付。C2 输送工步逐 tick 核对瓶头朝下与接触支承，候选最大倾角为 10°。测试覆盖各瓶的交接与出线身份、非零关节角下 GLB 法兰与正运动学一致，以及中途停止后仍持瓶。

候选验证使用虚拟夹具、输送带支承代理和瓶体网格凸包。机械臂连杆间的全包络碰撞和实体设备的关节限位、工具标定仍需单独验收。历史间接交接清单位于 `legacy/indirect-transfer`。
