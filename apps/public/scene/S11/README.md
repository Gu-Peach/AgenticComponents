# S11 人工搬运与转台分度焊接

[工艺 DSL](process.py) 沿用四件工单。首件使用 GLB 中小车上的 `Workpiece`，其余三件在上一件交付后按同一模型依次供料。人物从小车搬到装卸工装，转台沿正向旋转 180°。焊接机器人对准工件加工口、执行加工并退位。转台沿同一方向再次旋转 180°，人物将成品送回小车。现场只有一件在制品。

| 实例 | 模型与接口 | 动作及验证 |
| --- | --- | --- |
| H1 | `Human`，肩、肘、腕分别绑定 `RArm_00Sn`、`RElbow_00Un`、`RWrist_00Wn` | `carry_material` 使人物平移接近、吸附、搬运、放置并撤回。手掌吸附点取真实掌面网格 `Mesh_0A7g` 的下沿，初始高度约 0.710 m。肩肘随动，使可见手掌在抬放时对准物料，双脚保持地面高度。 |
| T1 | `Indexing_Table(center)`，转子 `Link1_005n`，装卸接口 `slot1` 取 `Mesh_03dg` 顶面中心 | `rotate_to_station` 要求同一物料在工装上，人物撤离且机械臂已退位。角度目标为 180° 和 0°，执行正向分度。到角、停稳且工件仍受工装约束后完成。 |
| R1 | `robot(ARC-2000i)`，六个 Axis 关节、法兰 `mountplate_00Fn`、焊枪尖 `Link2_00In` | `process_material` 把焊枪 `torch` 对准物料的 `weld` 加工口。工件静止且两接口对准后累计加工时间，完成加工并退位。 |
| F1 | `Pallet_Trolley` 小车，供料和交付共用 `F1.work` | 跟踪批次准入与成品交付，上一件移出后才接纳下一件。 |
| M01–M04 | `Workpiece`，搬运口 `handle`、加工口 `weld` | 加工作为物料的状态，机械臂成功完成焊接后将同一工件从 `raw` 变为 `finished`。几何外观沿用原模型。 |

## 模型绑定和仿真参数

装卸工装的中心在世界坐标约 (−0.48, 0.70, 0) 米，绕竖直轴半圈后抵达 (+0.48, 0.70, 0) 米。整个旋转过程工件跟随同一工装，小车和转台底座保持固定。

GLB 提供真实的右手和焊枪尖节点；两个物料接口采用工件网格上的候选点。抓取口位于 `Mesh_038g` 的水平上表面。加工口位于 `Mesh_036g` 的水平上表面。两点均取模型三角形内部，物料局部坐标相对 `Workpiece` 节点，外法向朝上。焊枪尖对准加工口时朝向该表面。加工状态和退出条件见 [工件契约](contracts/workpiece.json) 与 [独立验收目标](task-spec.json)。

单件质量沿用既有的 1 kg 仿真假设。默认加工时间 2 仿真秒，位置容差 8 mm，工具轴向容差 3°。转台角速度上限 90°/s、角加速度上限 180°/s²。机器人六关节采用候选局部轴与 GLB 零位，工艺以枪尖对接和停留模拟。旧版装夹工站和批次资料保存在 `legacy/original-welding/`。
