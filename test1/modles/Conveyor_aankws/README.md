# Conveyor_aankws 接触式输送实验

设备版本 0.5.0，契约 1.2。两个纯空间吸附接口的位置不变：入口 [-0.749,0.700,0]、出口 [0.751,0.700,0]，单位 m，forward 分别 -X/+X，up 为 +Y。

首期执行能力为单条水平、单位缩放、无模型导入偏移的输送机，加一个 0.10 m 立方体、0.2 kg 实验物料。Jolt 单线程接触物理驱动物料，不进行端点插值。有效带长 1.4 m、宽 0.5 m、顶面高 0.7 m；端点间距 1.5 m 是空间连接几何，不能据此扩大碰撞带面。

模板：conveyor.continuous-contact@1。显式实验配置：apps/src/data/runtime-fixtures/conveyor-box.json、conveyor-calibration.json；碰撞体厚度 0.1 m、摩擦 0.6、入口/出口检测范围等均为仿真配置，非真实硬件额定值。

从公共目录添加新版设备，在右侧“接触式运行”点击“启动输送实验”。支持调速、受控停带、暂停/继续、停止和重置。当前到达出口后实验策略自动提交一次停带请求；到达任务成功不等于向下游交接完成。物料位置只由物理后端写入，运行和重置不修改项目初始位姿。

已有项目使用旧定义时不自动升级；从新项目添加新版，或显式迁移旧定义后使用。legacy PreviewController/AnimationAdapter 路径尚未接入新场景会话，右侧旧行为预览仍不能据此启动真实接触世界。新增场景实验与旧 MOCK 预览互斥。

运行输入支持 runTag、speedTag；反馈和内部观测由模板与引擎发布。其他声明的服务/PLC 身份/脉冲端口尚未实现，详见 schema.runtime_execution_contract.supported_io。物料源、机械臂、仓储、载具等模板仅保留接口；没有实现下游交接、PLC 执行或资源优化调度。
