# 十二场景流程索引

所有场景采用ac-declarative/0.3；条件自动从契约导入，均为待运行验证的声明。

| 场景 | 工艺组织 |
| --- | --- |
| [S01](processes/S01/process.py) | 定距输送并停稳→双工位并行取放、退位、出口运输和交接；契约自动门控，三盘五拍。 |
| [S02](processes/S02/process.py) | 每组三盘：三次定距推进填充三个工位→三机械臂并行拆垛→三次推进排空；组间确认全部空盘已移走。 |
| [S03](processes/S03/process.py) | 三个常驻有限分支并行：上料、中央输送、下料；由物料到位和容量约束衔接。 |
| [S04](processes/S04/process.py) | 三个常驻有限分支并行：上料、中央输送、下料；由物料到位和容量约束衔接。 |
| [S05](processes/S05/process.py) | 共享进出料线的有界逐件循环，按订单返工标记显式分支；不把等待或额外工序隐含在脚本函数里。 |
| [S06](processes/S06/process.py) | 输入输送、转位单元和输出输送并行；转位单元内部按工步串行并确认退位。 |
| [S07](processes/S07/process.py) | 入库批次形成库存屏障；随后取货与出口输送并行，共享X1的动作由契约仲裁。 |
| [S08](processes/S08/process.py) | 入口输送、单机上下料加工、出口输送三个分支并行；单机工步内部顺序执行。 |
| [S09](processes/S09/process.py) | 双机加工并行，输入/输出分支并行，R1由契约资源仲裁互斥服务。 |
| [S10](processes/S10/process.py) | 逐盘有限循环、盘内逐件码放、真实换盘确认后进入下一盘。 |
| [S11](processes/S11/process.py) | 共用装卸台和回转单元，按有限订单串行完成焊接、转位和下料。 |
| [S12](processes/S12/process.py) | 入口、A面加工及转位交接、B面加工、出口四分支并行；A面完成并松夹后才允许转位交接。 |
