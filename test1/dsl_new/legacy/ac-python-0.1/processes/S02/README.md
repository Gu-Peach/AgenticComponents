# S02 六托盘按空闲工位分配、并行拆垛与空盘出线

整线共同启停；一波最多3盘到位后停带，三工位并行逐件拆垛，全体退位后空盘出线。

本批共 24 件物料、6 个任务载具；每件身份和归属见 [batch.json](batch.json)。

[process.py](process.py) 定义循环/并发与行为调用，[bindings.json](bindings.json) 定义外部到料、资源和适配假设，[task-spec.json](task-spec.json) 按完整批次独立验收。

- 所有托盘间距与三个停靠工位必须兼容共同驱动；运动计划检查器不接受需托盘独立启停/超车的计划。
- 每波可从1到3盘，只选择沿线可达且空闲可接料的工位；无可用工位时等待，不丢弃未分配托盘。
- 波内全部工位结束并退位才可移动主线；此基线不声称拆垛时其他托盘还能在同一主线上移动。

当前为可静态解析的控制规范，尚未接入实际调度和物理执行。
