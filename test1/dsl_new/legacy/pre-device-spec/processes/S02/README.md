# S02 声明式工艺

三工位批组并行拆垛：显式主线入站→par三个工位→空盘出站；波次间有证据屏障。

本批 24 件、6 个流转载具。生产清单在batch.json，控制顺序与并行在process.py，目标在task-spec.json。

- 采用固定站位批组，等待所需工位可用后放行；不再把工位策略藏进dispatch函数。
- carrier_plan是版本化派生计划表达式，必须验证共同驱动和最后不足三盘的映射，不执行瞬移。

动作调用是契约引用，不是Python函数执行。新版前端静态检查控制树及绑定；运行器、资源/容量协调和实际设备证据尚待接入，不能把声明的par当成已测得的并行性能。
