# 研究点一：验证算法与场景数据集设计

本文档目录将 [研究定位](../../docs/method.md) 落实为算法构造和数据集建设方案。当前交付为设计文档和真实资产清单，不表示求解器、数据集或实验结果已完成。

| 文件 | 内容 |
| --- | --- |
| [算法构造方案](算法构造方案.md) | 算法输入输出、模块文件树、状态语义、性质、求解、反例重放、实施顺序 |
| [数据集构建方案](数据集构建方案.md) | 12 个场景的候选任务、72 个父案例、576 个候选案例的数量依据、数据格式与划分 |
| [scene-inventory.json](scene-inventory.json) | 原始 GLB/PNG 的路径、哈希、节点与网格等实际检查信息；规划数量单独记录 |

建议先完成 S04 双机器人搬运的符号模型与独立任务规格，再实现小规模显式探索和有界求解。当前算法支持自定义符号场景，GLB、图片及节点映射均为可选信息。三维几何可达性、真实动作接入、任务规划、派工优化分别保留边界。

数据集数量口径：12 个资产场景来源不等于 12 个经审核的工艺模型；72 个父案例与其变体也不构成 576 个独立统计样本。本文提出的数据规模细化并替代 `dsl/docs/method.md` 第 6.2 节的初始规模估算，原文的 D-S/D-V/D-X/D-E/D-R 分类仍沿用。

当前已交付 S04-P01 及七个变体、参考检查器与轨迹，见 [S04 试验说明](../README-pilot.md)。算法构造文档中的通用架构仍为后续设计，不因试验通过而视为全部实现。

全量候选输入已构造：72 个父例、576 个案例、12 组 DSL/ST 候选和 36 组变更任务；见 [全量构造说明](../README-corpus.md)。结构检查与 ST 编译已完成，独立路径真值及等价性待验证。

方法一验证器的当前实现、命令和边界见 [README-method1.md](../README-method1.md)。只做契约驱动的执行路径验证；PLC 生成和优化派工未纳入。

四步实验完善已落到 [README-experiment-v2.md](../README-experiment-v2.md)：冻结语义、保持型反馈、独立协议参考、证据准入核心集与独立压力集。
