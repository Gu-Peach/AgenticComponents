# R1 批次说明

本批次实施[下一轮重点方案](../../../docs/下一轮重点实验与PLC对比实施方案.md)中的诊断与预算实验。运行入口和恢复方法见 [README-r1](../../README-r1.md)。

## 冻结范围

- 原 P5 共同语义与独立真值保持不变；运行前复查原准入门禁。
- 结构清单覆盖 360 个语义案例；预算实验复用 P5 的 24 个分层样本及其实际 profile。
- 诊断补充 S04-P01，覆盖原试点的 stop_unknown_c1 特殊环境。
- 2,592 个预算作业：三方法 × 四预算（0.5、2、10、30 秒）× 三次重复。
- 75 个独立剖析、27 个状态上限敏感性、27 个内存上限敏感性和 36 个已有 K 子集诊断。
- 总计 2,757 个作业，搜索预算之和上界 28,302 秒（约 7.86 小时），另有前处理、启动、证据整理和重放开销。
- 单 worker 运行，配对块内轮换方法，剖析与性能作业分开。组内查询和 Portfolio 阶段共享预算。

## 数据与恢复

原始数据位于 algorithm/datasets/ac-path-v1/experiments/next-round-v1/：

- plan.json、freeze.json：样本、参数、源码/输入与独立真值摘要。
- source-snapshot/、inputs/：固定源码副本及无标签查询组。
- plc-pilot/：工具 PATH 探测、ST 合并输入和编译回执。
- jobs/、attempts/、wall-times/：逐作业封存输出、异常尝试及父进程墙钟。
- progress.json、launch.json、logs/：实时数量、进程来源及运行日志。
- completion.json、prediction-manifest.json：全部预测封存后生成。
- scores/：仅在全部预测封存后连接独立 gold 评分。

实时进度以 progress.json 和运行日志为准。本说明不把后台启动视为全部作业结束。代码/输入漂移会停止批次；恢复必须使用相同冻结版本。正常机器关机或进程退出后，按 README-r1 中的 run 命令恢复，已封存作业不按效果重跑。

全部作业结束后自动生成逐查询评分、稳定覆盖、资源原因及预算图表，写入同目录 R1实验报告.md 和 budget-coverage.png。自动报告中的完成状态与人工审核分开。
