# 方法一全量 full / auto 实验

实验日期：2026-11-02。范围为当前核心数据集全部 576 个案例，在 nominal 环境下比较未优化 full 与自动约简 auto。每方法、每案例运行一次，形成 1,152 个主作业；另对预先记录的 6 个受干扰配对整体补跑 12 次。没有修改算法、案例、目标或答案标签。

直接打开 [离线图表页面](run/charts/index.html)，或阅读 [完整图文报告](run/charts/report.md)。六组图均提供 PNG 和 SVG，数据表为 [jobs.csv](run/charts/jobs.csv)。

## 主要结果

| 指标 | full | auto |
| --- | ---: | ---: |
| 结构错误组拒绝数 | 216 | 216 |
| 语义组固定分母 | 360 | 360 |
| 有限模型穷尽 | 84 | 176 |
| 穷尽率 | 23.3% | 48.9% |
| 搜索超时 | 276 | 184 |
| 工作进程失败/看门狗超时 | 0 | 0 |

本轮优势是 **同预算下覆盖更多模型**：auto 多穷尽 92 个模型，提升 25.56 个百分点。双方都穷尽 84 个，仅 auto 穷尽 92 个，双方未穷尽 184 个，没有仅 full 穷尽的案例。

这不意味着 auto 对所有案例普遍更快。共同完成的 84 例中，`full/auto` 搜索耗时比中位数为 **0.68184**，小于 1 表示这个子集上 auto 通常耗时更多。该子集包括 72 个 DV01、6 个 DV04、3 个父例、3 个 DV03，明显偏向顺序/门控错误类。不能将该中位数外推到全部案例，也不能从一次计时断言额外耗时的具体原因。

实际 auto 策略为 clock 315 例、compact 45 例；共同完成子集为 clock 74、compact 10。该实验评价自适应策略整体，不是隔离某一个优化模块的消融试验。

V09 在双方有明确结论的 87 对上全部兼容；V10a 为 86 对全部兼容。没有输入、模型或源码哈希不一致，也没有发现明确相反结论。**这不是 100% 准确率**：全量独立真值尚未建立，未知结论不参与一致率计算。

## 实验条件

- 正常环境 nominal；时间界限 3,000 tick（60Hz 模型时钟约 50 秒），不是运行全部 query-plan 环境/界限组合。
- 每次搜索限时 1 秒、最多 20,000 状态、512 MiB 内存预算；每个工作进程另设 20 秒看门狗。
- 独立进程、串行计时；案例随机顺序，方法顺序平衡交替，种子 20261102。
- 搜索时间单列；工作进程内总耗时包括绑定、建模、搜索和重放，不含启动及结果序列化。另存含启动的墙钟耗时。
- 无并发求解，无源码或数据清单漂移。硬件、Python 与源码摘要见 [config.json](run/config.json)。

早期图表合成样式检查与六个配对存在时间重叠，因此按预先记录的时间窗重跑两种方法，而非按结果挑选重测。原始记录保存在 `run/results.jsonl`，补跑保存在 `run/reruns/`，最终统计使用 `run/analyzed-results.jsonl`；[选择审计](run/selection-audit.json) 和 [干扰记录](run/interference-audit.json) 给出全过程。

## 证据与复现

- `run/completion.json`：主作业完整性和源码/清单稳定性。
- `run/jobs/`：每个原始作业的完整结果；`run/reruns/` 保留补跑结果。
- `run/analysis-config.json`：固定 360 个语义案例、216 个结构错误案例的统计分组。
- `run/charts/stats.json`：全部指标、兼容性、分组与异常诊断。
- `run/charts/report.md`、`index.html`：图表阅读入口。

复现实验应使用新的输出目录，避免覆盖原始证据：

```powershell
python -B run_experiment.py --workspace E:/project/AgenticComponents/test1/dsl/algorithm --output rerun-new
```

`chart_report.py` 根据最终 JSONL 和带固定分组的分析配置绘图；`finalize_run.py` 是本次已记录干扰的补跑/选择脚本，不应无条件用于没有同类干扰的新实验。

本轮没有 PLC/ST 对比，也没有计算精确率、召回率或独立真值准确率。完整路径搜索未结束时保留 UNKNOWN；有限模型穷尽也不等于工艺正确。正式论文实验仍需更高预算、重复测量、独立核验集和按父例/场景分组统计。
